# webauthn-viewer

WebAuthn response viewer for learning.

https://inabajunmr.github.io/webauthn-viewer/

![image](image.gif)

## Project setup

Use Node.js 20.19+ (20.x), 22.13+ (22.x), or 24+.

```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lint
```
npm run lint
```
